# freesense, FreeSense 2.0 (experimental)

System source, WebUI and installer; `native/` holds the C helpers.

FreeSense 2.0 is a rebuild for fresh installations. It is not released and not supported. FreeSense releases come from the
`main` and `RELENG_*` branches.
