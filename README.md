# freesense-os-base, FreeSense 2.0 (experimental)

FreeBSD patches, boot images, build driver (`build/`), automation and, under `workspace/`, the shared
tools. The planning notes some documents link to are not published.

FreeSense 2.0 is a rebuild for fresh installations. It is not released and not supported. FreeSense releases come from the
`main` and `RELENG_*` branches.
